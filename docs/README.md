# Magic Particles Lib Docs

This directory contains usage and integration docs for reusable library features.

## Sections

- [Premade particles](./premade-particles/README.md)
- [Integration](./integration/README.md)
- [Reusable systems](./reusable-systems/README.md)

## Intended structure

- `premade-particles/` for ready-to-use particle implementations exposed by MPL
- `integration/` for registration, datagen, and library setup notes
- `reusable-systems/` for larger reusable APIs such as mesh/extrusion tooling

This layout is intended to scale as more premade particles and reusable APIs are added.
